# Saree Sansar — 100% Pure JavaScript MERN Stack Project

Complete MERN Stack E-Commerce without any TypeScript.
Built with:
- **M**: MongoDB (Mongoose)
- **E**: Express.js
- **R**: React 19 (JSX)
- **N**: Node.js

## 📁 Structure:
- `client/` : Pure React 19 Frontend (Vite + Tailwind CSS)
- `server/` : Pure Node.js + Express + MongoDB REST API

## 🚀 How to Run:
### 1. Start Backend:
```bash
cd server
npm install
npm run dev
```

### 2. Start Frontend:
```bash
cd client
npm install
npm run dev
```
