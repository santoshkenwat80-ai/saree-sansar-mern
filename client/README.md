# Saree Sansar — Pure JavaScript React Frontend (No TypeScript)

Pure React 19 + Vite + Tailwind CSS Luxury Saree E-Commerce Frontend.

## 🚀 How to Run:
```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

The app will start on http://localhost:5173 (or 3000) and connect to the Node.js Express backend at http://localhost:5000/api.
